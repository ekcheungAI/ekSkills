# Platform URL Patterns

Use these public URL patterns for initial social username screening. A missing public page is not proof that the username can be registered.

| Platform | URL Pattern | Availability Signal |
|---|---|---|
| Instagram | `https://www.instagram.com/{handle}/` | Public profile means likely taken. Login walls, redirects, or 404s need manual confirmation. |
| TikTok | `https://www.tiktok.com/@{handle}` | Public profile means likely taken. Some unavailable handles do not expose public pages. |
| X | `https://x.com/{handle}` | Public profile means likely taken. Suspended or protected accounts may still block registration. |
| Threads | `https://www.threads.net/@{handle}` | Usually tied to Instagram availability; verify through Instagram too. |
| YouTube | `https://www.youtube.com/@{handle}` | Public channel means likely taken. Handle availability must be checked inside YouTube. |
| Pinterest | `https://www.pinterest.com/{handle}/` | Public profile means likely taken. |
| Facebook | `https://www.facebook.com/{handle}` | Public page/profile means likely taken. |
| GitHub | `https://github.com/{handle}` | 200 means taken; 404 often means available, but reserved names exist. |
| Etsy | `https://www.etsy.com/shop/{handle}` | Public shop means taken or historically used. |
| Shopify | `https://{handle}.myshopify.com` | Resolving shop means likely taken. |

For consumer brands, inspect the page content before judging conflict severity. An inactive unrelated personal account is less risky than an active brand in the same category.
